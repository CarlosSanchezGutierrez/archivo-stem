# Archivo STEM

Plataforma digital para documentar, preservar y explorar trayectorias STEM mediante entrevistas, perfiles de investigadores, grafos de conocimiento, líneas temporales, transcripciones enriquecidas con IA y rutas de aprendizaje para estudiantes e instituciones.

## Visión

Archivo STEM no es solo un podcast. Es un archivo vivo de conocimiento técnico, científico y profesional.

El objetivo es dignificar la trayectoria de investigadores, ingenieros, científicos, profesores y profesionistas STEM, convirtiendo sus entrevistas, libros, papers, patentes, proyectos y cursos en experiencias explorables.

## Stack inicial

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- pgvector
- Vercel
- Knowledge Graphs
- IA para transcripciones, resúmenes, búsqueda semántica y roadmaps personalizados
