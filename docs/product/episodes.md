# Episodios — Archivo STEM

Los episodios no son publicaciones aisladas. Cada episodio debe convertirse en una pieza de archivo.

## Componentes de un episodio

- Video completo
- Audio
- Clips
- Transcripción
- Ideas clave
- Timestamps
- Recursos conectados
- Preguntas para estudiantes
- Perfil del invitado
- Temas conectados
- Extractos para redes
- Material para instituciones

## Objetivo

Convertir entrevistas en conocimiento navegable, estudiable y reutilizable.

## MVP

- Página de episodios
- Filtros
- Buscador
- Página individual
- Clips placeholder
- Transcripción preview
- Recursos conectados
- Preguntas de discusión

## Fase 2

- Embed real de YouTube
- Audio
- Transcripción completa
- Clips con timestamps
- Relación con biblioteca
- Relación con Atlas STEM

## Fase 3

- Transcripción navegable
- Búsqueda semántica
- Extracción automática de ideas
- Generación de guías educativas
- Resumen con IA
- Capítulos automáticos

## Fase 4

- Chat con episodio
- Preguntas vivas con IA
- GraphRAG sobre episodio + perfil + biblioteca
- Colecciones institucionales automáticas
