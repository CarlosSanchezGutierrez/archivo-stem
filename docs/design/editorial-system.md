# Sistema editorial de Archivo STEM

## Identidad

Archivo STEM no debe sentirse como una landing genérica hecha con IA.

Debe sentirse como:

- Archivo académico.
- Museo digital.
- Repositorio de trayectorias.
- Plataforma de conocimiento.
- Infraestructura cultural para educación STEM.

## Tono

Usar un tono:

- Sobrio.
- Preciso.
- Institucional.
- Académico.
- Técnico, pero entendible.
- Inspirador, sin frases vacías.

## Evitar

- Emojis.
- Exceso de símbolos decorativos.
- Frases motivacionales genéricas.
- Copys tipo startup artificial.
- Tarjetas repetitivas sin jerarquía.
- Gradientes exagerados.
- Nodos gigantes en grafos.
- Cajas blancas por defecto.
- Textos en minúscula cuando son títulos o secciones.

## Regla de capitalización

Usar estilo oración en español:

Correcto:
- Rutas de aprendizaje
- Modo institución
- Red de conocimiento
- Biblioteca curada

Evitar:
- rutas de aprendizaje
- modo institución
- red de conocimiento

## Frase rectora

Archivo STEM preserva trayectorias, obras y relaciones de conocimiento en ciencia, tecnología, ingeniería y educación.

## Diseño

La interfaz debe parecer construida para durar años, no para una campaña temporal.
