# Pulido 04 — Episodios

## Problema detectado

La sección de episodios todavía podía parecer una página común de podcast.

## Cambio aplicado

Se cambió el enfoque hacia:

- Registro audiovisual.
- Ficha documental.
- Capítulos de estudio.
- Extractos contextualizados.
- Transcripción de estudio.
- Recursos conectados.
- Uso educativo.

## Criterio

Cada episodio debe poder:

1. Verse como entrevista.
2. Leerse como documento.
3. Usarse como material educativo.
4. Conectarse con el perfil del invitado.
5. Alimentar biblioteca, rutas y Atlas STEM.

## Siguiente paso

Pulir Biblioteca para que no parezca catálogo genérico, sino archivo curado de objetos de conocimiento.
