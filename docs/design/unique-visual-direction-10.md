# Pulido 10 — Dirección visual propia de archivo/museo

## Problema detectado

Aunque la página ya era más sobria, todavía podía sentirse cercana a una landing genérica de IA.

## Cambios aplicados

- Marca visual de Archivo STEM con retícula interna.
- Sellos de catalogación.
- Dossiers visuales.
- Tiras de metadatos.
- Lenguaje visual de archivo técnico.
- Panel tipo plano o blueprint.
- Códigos de registro.
- Mejor jerarquía en hero.
- Sistema visual menos startup, más museo/documentación.

## Principios visuales

1. No usar emojis.
2. No depender de gradientes llamativos.
3. No usar cards genéricas sin función documental.
4. Cada sección debe parecer parte de un archivo.
5. Cada elemento debe sugerir catalogación, preservación, relación o consulta.

## Palabras visuales clave

- Dossier.
- Registro.
- Sala.
- Objeto.
- Red.
- Colección.
- Catálogo.
- Trayectoria.
- Obra.
- Legado.
