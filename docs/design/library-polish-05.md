# Pulido 05 — Biblioteca

## Problema detectado

La biblioteca se sentía como un catálogo genérico de recursos.

## Cambio aplicado

Se cambió el enfoque hacia:

- Objeto de conocimiento.
- Registro de biblioteca.
- Criterio de relevancia.
- Sala relacionada.
- Mesa de consulta.
- Colección curada.

## Criterio

Cada recurso debe responder:

1. Qué es.
2. Quién lo creó.
3. A qué persona o institución se conecta.
4. Qué temas documenta.
5. Por qué pertenece al archivo.
6. Qué puede aprender un estudiante al explorarlo.
