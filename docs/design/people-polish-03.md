# Pulido 03 — Personas y perfil individual

## Problema detectado

La página de personas y el perfil individual todavía se sentían como componentes genéricos de landing page.

## Cambio aplicado

Se movió el lenguaje visual hacia:

- Ficha de archivo.
- Sala de archivo.
- Obra publicada.
- Proyectos representativos.
- Línea temporal.
- Red de conocimiento.
- Cápsula del tiempo.

## Criterio

Cada persona debe sentirse como una exposición digital, no como una card de invitado.

## Siguiente paso

Pulir Episodios para que no parezcan una página de podcast tradicional, sino una ficha documental con capítulos, clips, transcripción, recursos y uso educativo.
