# Pulido 02 — Homepage

## Problema detectado

La página inicial se sentía demasiado genérica:

- Copys amplios.
- Tarjetas repetidas.
- Secciones sin suficiente identidad.
- Sensación de landing hecha con IA.
- Falta de una narrativa propia de archivo.

## Cambio aplicado

La homepage ahora gira alrededor de cinco ideas:

1. Documentar lo que normalmente queda fuera de la memoria pública.
2. Tratar cada trayectoria como una exposición.
3. Mostrar la obra completa de una persona.
4. Diseñar el sistema como grafo de conocimiento.
5. Usar el archivo en modos distintos: estudiante, institución y red personal.

## Criterio

Cada sección debe justificar por qué Archivo STEM no es un podcast, sino una infraestructura cultural y educativa de conocimiento STEM.
