# Rediseño Premium Global — Archivo STEM

## Dirección

Archivo STEM debe sentirse como museo digital de trayectorias STEM.

No debe parecer:

- podcast casual
- sitio motivacional
- landing genérica
- página de YouTube
- proyecto estudiantil improvisado

Debe parecer:

- archivo académico
- laboratorio digital
- museo de ingeniería
- repositorio cultural
- plataforma educativa seria
- red de conocimiento

## Header

La navegación se reduce para evitar saturación:

Visible:
- Personas
- Episodios
- Atlas
- Rutas

En "Más":
- Biblioteca
- Instituciones
- Mi Red STEM
- FAQ

Botón externo:
- Puente Impacto

## Estilo

- Fondo oscuro
- Azul institucional
- Cards translúcidas
- Grids técnicos
- Brillos sutiles
- Bordes suaves
- Animaciones discretas
- Lenguaje académico claro

## Principio visual

La personalidad debe venir del sistema visual, no de decoración excesiva.
